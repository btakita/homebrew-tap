# homebrew-tap

Homebrew tap for btakita CLI tools.

## Install

```bash
brew tap btakita/tap
brew install chromium-bridge
brew install agent-doc
```

Or install directly without persisting the tap:

```bash
brew install btakita/tap/chromium-bridge
brew install btakita/tap/agent-doc
```

## Upgrade

```bash
brew update
brew upgrade chromium-bridge
brew upgrade agent-doc
```

## agent-doc

`Formula/agent-doc.rb` is generated by agent-doc's `scripts/bump-homebrew-formula.py`
from each release's `SHA256SUMS`; the agent-doc Release workflow (`homebrew.yml`)
rewrites and commits it on every tag. Do not edit it by hand.

The formula installs the `agent-doc` binary and its native library
(`libagent_doc.so` / `libagent_doc.dylib`) side by side in `libexec`, with
`bin/agent-doc` as an exec wrapper, so `agent-doc lib-path` finds the library.

macOS archives are built by the operator after each tag. Until they are uploaded
the formula is Linux-only (`depends_on :linux`); uploading them re-runs the bump
and adds the macOS blocks.
